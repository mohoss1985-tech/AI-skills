### 6 · How to import

| Step | Xray Cloud | Xray Server / Data Center |
|---|---|---|
| 1. Manual tests | Test Case Importer › CSV › map *Test ID* to *Test Case Identifier*, *Action · Data · Expected Result* to the step fields, tick *Create folders* | Same importer; older versions call *Action* "Step" |
| 2. Cucumber tests | Xray › Import Cucumber Tests, or `POST https://xray.cloud.getxray.app/api/v2/import/feature?projectKey=LUM` | Xray › Import Cucumber Tests, or `POST https://<jira>/rest/raven/1.0/import/feature?projectKey=LUM` |
| 3. Results | Test Execution › Import Execution Results, or `POST …/api/v2/import/execution` with `results-cloud.json` | Same, or `POST https://<jira>/rest/raven/2.0/import/execution` with `results-server.json` |
| Authentication | Client ID + secret → token (24 h) | Jira personal access token |

> ⚠️ **Avoid duplicate tests.** The results file creates any test that has no Jira key yet. Either import steps 1–2 first, put the keys Xray gives into the spec and rebuild the results, or skip steps 1–2 and let the results file create the tests with their results in one go.
